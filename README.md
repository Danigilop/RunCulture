# RunCulture

Android-приложение для городских прогулок. Оно показывает достопримечательности на карте и открывает персонажей и исторические факты, когда пользователь оказывается рядом с интересным местом.

**Стек:** Kotlin, Android Views (XML, Fragment, View Binding), Yandex MapKit Lite, Room, Coroutines.

## Как устроен проект

Координаты достопримечательностей и исторический контент берутся из встроенного набора данных. Yandex MapKit отображает карту и метки, а координаты пользователя поступают от Android `LocationManager`.

1. `RunCultureApplication` создаёт базу Room и передаёт в `AppRepository` четыре DAO: для пользователей, достопримечательностей, персонажей и фактов. При запуске `DatabaseInitializer` заполняет базу данными из `LandmarksData`.
2. `MapFragment` получает достопримечательности через `AppRepository` и добавляет метки на карту.
3. Когда пользователь подходит к точке на расстояние до 100 метров, приложение предлагает открыть персонажа. После подтверждения персонаж и связанные факты сохраняются в разделе достижений.
4. `RegisterActivity` и `LoginActivity` работают с локальными профилями через `AppRepository`. После входа идентификатор пользователя сохраняется в `SharedPreferences`.

## Запуск

Откройте проект в Android Studio, синхронизируйте Gradle с Android SDK 36 и запустите модуль `app` на Android 8.0 (API 26) или новее. Разрешите приложению доступ к точной геолокации. На эмуляторе можно задать координаты рядом с одной из точек из `LandmarksData.kt`.
